# Programs
Implementation of various data structures and work with them

## What data structures were affected?
  1. Binary heap
  2. AVL tree
  3. B-tree map
  4. Hash map
  5. Graphs

## What algorithms are implemented for graphs
  – depth-first search;
  – breadth-first search;
  – Dijkstra's algorithm;
  – Kruskal's algorithm;
  – Prim's algorithm;
  – Floyd-Warshall algorithm;
  - Tarjan's algorithm for topological sorting;
  - Fleury's algorithm;
  - Euler cycle search algorithm based on cycle union;
  - Kosaraju's algorithm;
